# Day 16 - Student Wellbeing Statistical Analysis & Probability

## Overview
This project analyzes a Student Wellbeing Survey dataset using descriptive statistics and probability concepts in Python. The notebook demonstrates statistical analysis, outlier detection, probability calculations, Bayes' theorem, and normal distribution concepts using Pandas.

## Objectives
- Inspect and understand the dataset
- Calculate measures of central tendency
- Calculate measures of dispersion
- Detect outliers using the IQR method
- Compare statistics before and after removing outliers
- Perform probability and conditional probability analysis
- Verify conditional probability using Bayes' Theorem
- Analyze Academic Readiness Score using Z-scores and the Empirical Rule
- Summarize key statistical insights

## Key Findings
- Academic Readiness Score showed the highest variability among the selected variables.
- Monthly Discretionary Spending contained the highest number of outliers.
- Removing outliers reduced the mean spending more than the median, demonstrating the influence of extreme values.
- Students with part-time jobs and high stress scores did not appear to be independent events.
- Bayes' Theorem produced the same result as the direct conditional probability calculation, validating the analysis.
- The highest Academic Readiness Score was approximately 2.71 standard deviations above the mean, while the lowest score was approximately 3.08 standard deviations below the mean.

## Outcome
This assignment demonstrates the practical application of descriptive statistics, probability, Bayes' theorem, and normal distribution concepts for analyzing student wellbeing data and extracting meaningful statistical insights.
